# 듀오 아케이드 (DUO ARCADE)

둘이서 같이 하는 협동·대결 미니게임 웹앱(PWA).

- **한 기기로 둘이**: 폰 하나를 마주 보고 놓고 위·아래에서 조작. 인터넷 없이(비행기 모드) 동작.
- **각자 기기로**: 4자리 코드로 연결(PeerJS 무료 공개 서버 + P2P). 방장이 수락해야 입장.
- 대결 7종 · 협동 3종, 소원권, 캐릭터 만들기/꾸미기, 협동 진행 자동 저장.
- 저장 데이터는 각 기기 브라우저에만 저장되고 서버로 보내지 않음.

외부 라이브러리: [PeerJS](https://github.com/peers/peerjs) (MIT, `js/vendor/peerjs.min.js`).
